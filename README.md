This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Book list is a simple fullstack project based on Next js, Prisma, PostGresql .

# Here I have used Prisma Console (prisma+postgresql) as a Database.

# I have used Prisma to talk to database

# used Next Auth for authentication

- I have built a admin panel here to add new book and display all the existing book in a single page as a list.

- One can delete a book from this list if wants.

- Also added a signup, login page 

- In the log in page I have implemented Google authentication and Credential based (email,password) authentication.

- First You have to sign up then login with same credentials.

- In the home page All my favourite books are available with details .

- If you click on a book card then , you will be redirected to a dynamic route with more details of the book.
